# Gates - 门禁执行层

静态分析和构建验证脚本，门禁系统的"执法者"。

## 门禁类型

| 门禁 | 作用 | 状态 |
|------|------|------|
| `ast-grep/` | AST 模式匹配 | 实现中 |
| `lint/` | 深度代码分析 | 待实现 |
| `error-prone/` | 编译器级别检查 | 待实现 |
| `build/` | 构建验证 | 待实现 |
| `security/` | 安全模式扫描 | 待实现 |

## 配置

所有门禁在 `config.yaml` 中统一配置。

## 执行方式

```bash
# 通过 hooks 自动触发
# 或通过 skills 手动调用
/gates check <files>
```
