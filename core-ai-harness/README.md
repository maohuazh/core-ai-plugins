# Core AI Harness

AI 增强开发系统 — 通过门禁（Gates）、钩子（Hooks）和规则（Rules）的协同，
实现代码质量的自动化保障。

> Rules 管"思想"，Hooks 管"纪律"，Gates 管"验证"。

## 架构概览

```
┌─────────────┐    ┌─────────────┐    ┌─────────────────────┐
│  Rules       │    │  Skills     │    │  Commands           │
│  (认知层)    │    │  (能力层)   │    │  (交互层)           │
└──────┬──────┘    └──────┬──────┘    └──────────┬──────────┘
       └──────────────────┼───────────────────────┘
                          ▼
┌──────────────────────────────────────────────────────────┐
│                    Hooks (事件层)                         │
│  SessionStart → UserPrompt → PreEdit → PostEdit → Stop  │
└──────────────────────────┬───────────────────────────────┘
                           ▼
┌──────────────────────────────────────────────────────────┐
│                    Gates (验证层)                         │
│  AST-Grep │ Lint │ ErrorProne │ Build │ Security        │
└──────────────────────────────────────────────────────────┘
```

## 目录结构

| 目录 | 作用 | 说明 |
|------|------|------|
| `rules/` | AI 认知层 | 自然语言规则，AI 生成代码时自动遵守 |
| `gates/` | 门禁执行层 | 脚本+配置+规则，机器执行的硬约束 |
| `hooks/` | 事件层 | 自动触发，编辑后增量扫描 |
| `skills/` | 能力层 | 按需调用的复杂操作编排 |
| `commands/` | 用户入口 | 斜杠命令 |

## 快速开始

安装到项目：

```
/gate-install
```

手动检查：

```
/gates check --changed
/gates check src/main/java/**/*.java
```

## 核心理念

1. **Rules 管"思想"** — 告诉 AI 应该怎么做，让 AI 第一次就写对
2. **Hooks 管"纪律"** — 自动触发，不需要人记得去跑
3. **Gates 管"验证"** — 零容忍的最终防线
